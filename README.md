# Flat Cleaning Schedule | جدول نظافة السكن

An automated, bilingual (English / Arabic) 4-week roommate cleaning rotation web application for **Saif, Wesdom, Mohammed, and Saber**.

## Features
- **Clean Light Theme**: High-contrast, mobile-first light aesthetic.
- **Visual 7-Day Date Strip**: Shows the exact dates of the current week, highlighting **Sunday (Start)** and **Monday–Tuesday (2-Day Grace Window)**.
- **Calibrated Rotation**:
  - **Week 1 (Oct 18, 2026)**: Finished
  - **Week 2 (Oct 25, 2026)**: Finished
  - **Week 3 (Nov 1, 2026)**: Starts automatically on Sunday, Nov 1 + active for 2 grace days (Mon Nov 2 & Tue Nov 3)
  - **Week 4 (Nov 8, 2026)**: Next in loop
- **Zero-Dependency Static Hosting**: Works out of the box on **GitHub Pages** and **Netlify**.
